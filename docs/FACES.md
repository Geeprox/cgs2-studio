# 表盘与交互

表盘编号固定为 0–13。机械翻牌已由空间透视替换；原厂表盘不占用选择列表。

| 编号 | 表盘 | 秒数显示 | 天气浮层 |
| --- | --- | --- | --- |
| 0 | Ultra Modular | 外框长刻度 | 可选 |
| 1 | Air Wayfinder | 外框长刻度 | 可选 |
| 2 | Infograph | 指针 | 可选 |
| 3 | 双模块 | 数字 | 可选 |
| 4 | XL Air | 无额外秒数 | 可选 |
| 5 | 空间透视 | 数字 | 无 |
| 6 | Chrono | 指针 | 可选 |
| 7 | 俯视泳池 | 无额外秒数 | 可选 |
| 8 | 天气剧场 | 时:分:秒 | 主题自身天气 |
| 9 | 涂鸦气象 | 时:分:秒 | 可选 |
| 10 | 流光仪表 | 无额外秒数 | 可选 |
| 11 | 构成·空气 | 无额外秒数 | 可选 |
| 12 | 星际观测 | 时:分:秒 | 无 |
| 13 | 声笺 | 数字 | 无 |

同一主题只使用一种秒数表达，不重复叠加进度条、边缘秒针和数字秒数。天气演示可切换晴天、晴夜、日/夜多云、阴、雨、雪、风、雾、雾霾、沙尘、雷雨，退出后恢复实际天气。

- 主菜单采用 3×3 点击卡片，底部只保留主菜单入口。打开表盘选择时定位到当前页。
- 空间透视采用不同朝向、尺寸、深度和线宽的正交排布；拖动参数调整位置，拖动空白区域调整视角，点击参数切换主指标。
- 泳池用三张常驻材质完成整屏水面运动，避免逐帧换图。泳圈沿波浪平移和摆动；拖动后保留目标位置，其他重叠参数被推开。
- 月相由 Astronomy Engine 依据当前时间计算光照比例与盈亏。图形是北向上的示意，不含所在地地平线倾斜或实时望远镜视角。
- 原生夜间计划对所有主题生效；照片轮播和动画在屏幕关闭时停止。60 秒无真实触摸后暂时降低背光，触摸恢复当前亮度目标，不改写用户手动/自动设置。

传感器状态与分级文字来自原生控制器；表盘只负责展示。配置和布局保存在设备上，语音转写不写入布局或偏好。

“天气背景”和“表盘动效”统一位于主菜单 → 显示与连接，与夜间息屏和连接状态放在同一页面。相册、视频播放和音乐播放各有独立入口。
